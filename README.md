# REPL.ai

A terminal-based (REPL) AI chat application supporting multiple LLM providers, inspired by OpenCode and Open WebUI as an alternative to Perplexity to search the web, automatically create news summaries and financial statistics, and OpenClaw to work with as copilot or companion on own tasks and control other agents and tools.

## Features

- Multi-provider chat (Ollama (local/cloud), OpenAI, Anthropic, ...)
- Session management (create, switch, export/import, autolog in .replai/sessions)
- Hideable streaming responses with thinking duration display (see OpenCode)
- Web search integration (compact summary, expandable details on demand)
- Slash command system (/help, /model, /provider etc., see OpenCode)
- Configurable via commands like "/provider ollama" or interactively
